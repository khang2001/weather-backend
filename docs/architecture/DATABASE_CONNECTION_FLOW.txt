═══════════════════════════════════════════════════════════════════════════════
                           SUMMARY
═══════════════════════════════════════════════════════════════════════════════

1. config.py          → Stores database URL
2. connection.py      → Creates engine & get_db()
3. models.py          → Defines User class (table structure)
4. routers/settings.py → API endpoints that use get_db()
5. web.py             → Registers all routes
6. Settings.jsx       → Makes fetch() calls

Key Magic: Depends(get_db)
- FastAPI automatically calls get_db()
- Provides database session to route handler
- Closes session when done (even if error)

Flow: Frontend → HTTP → FastAPI → get_db() → Session → ORM → SQL → PostgreSQL
Return: PostgreSQL → SQL Results → ORM → Python Objects → JSON → HTTP → Frontend
